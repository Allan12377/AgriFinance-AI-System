# Step-by-Step Roadmap

We will build AgriFinance AI one requirement at a time.

## Step 1: Finance records

Status: implemented in the starter codebase.

Farmer can add income and expense records, then see profit summary and simple advice.

## Step 2: Farmer profile and farm registration

Farmer can create a profile and register multiple farms.

Tables involved:

- users
- farmers
- farms

## Step 3: Backend database connection

Move finance records from temporary in-memory API storage to PostgreSQL.

## Step 4: Authentication

Add registration, login, password hashing, and JWT authentication.

## Step 5: Loans and savings

Track loans, loan payments, and savings.

## Step 6: Loan readiness

Use financial records to calculate a loan readiness score.

## Step 7: Market prices

Admin can manage crop prices by crop, district, market, and date.

## Step 8: Weather records

Integrate weather data or allow admin-managed weather records first.

## Step 9: AI recommendations

Move from simple rules to trained or data-driven prediction models when enough data exists.

## Step 10: Reports

Generate financial reports and export them for farmers, cooperatives, and loan officers.
