# AgriFinance AI Mobile App

This is the Flutter app for farmers.

## Current feature

Step 1 is a local finance dashboard:

- Add income records
- Add expense records
- View income, expenses, profit, and margin
- Read basic financial advice
- Delete records

## Run after installing Flutter

```bash
flutter create . --project-name agrifinance_ai
flutter pub get
flutter run
```

The `lib` folder already contains the AgriFinance AI app code.
