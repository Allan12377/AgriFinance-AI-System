# AgriFinance AI

This is the first working step for the AgriFinance AI system described in the proposal.

## Step 1: Farm finance records

The current version lets a farmer:

- add farm income records
- add farm expense records
- see total income, total expenses, net profit, and profit margin
- view simple financial advice based on the records
- export the visible records as a CSV file

For now, records are saved in the browser using local storage. That keeps the first step simple and easy to run. In a later step, we will connect the app to a backend API and a PostgreSQL database.

## Open the app

Open `index.html` in a browser.
